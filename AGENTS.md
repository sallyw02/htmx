# AGENTS.md

htmx is a dependency-free JavaScript library: `hx-*` attributes on HTML elements issue AJAX requests and swap the returned HTML into the page. This checkout is the 2.x line, which is in maintenance. Bug fixes with tests are welcome; new features need an issue a maintainer has accepted, and refactor-only or formatting-only changes get closed.

## Architecture

- `src/htmx.js` is the entire library: one IIFE split into sections marked by `//= ===` banner comments (Utilities, Node processing, History, Ajax, Extensions API, Initialization, and others).
- Main flow: `processNode` → `initNode` → `processVerbs` → `issueAjaxRequest` → `handleAjaxResponse` → `swap`.
- `test/core/` covers library behaviour and `test/attributes/hx-<name>.js` has one file per attribute. Helpers live in `test/util/util.js`.
- `www/content/` is the htmx.org docs site; each attribute has a page at `www/content/attributes/hx-<name>.md`.
- Source changes branch from `dev`; docs-only changes (only `www/`) branch from `master`. The `four` and `four-dev` branches are htmx 4, with a different layout this file does not describe.

## Commands

```bash
npm ci                     # npm install rewrites package-lock.json
npm test                   # lint + types-check + headless Chromium, ~10 s; this is what CI runs
npm run test:chrome -- --files test/attributes/hx-get.js   # one file, skips lint and types, ~1 s
npm run format             # eslint --fix
npm run types-check        # tsc --checkJs on src/htmx.js
```

Tests run in a real browser through web-test-runner and Playwright, which downloads its own Chromium on the first run, so CHROME_PATH is unnecessary. If that first run times out on one file, rerun before debugging. To debug in a browser, serve the repo root over HTTP and open `test/index.html`.

## Conventions

- Every function in `src/htmx.js` is a named declaration with JSDoc `@param` and `@returns`. `types-check` takes its types from that JSDoc, so new functions need it too.
- Keep new helpers private inside the IIFE. Tests reach them with `htmx._('functionName')`. The public `htmx` object and `internalAPI` are API for users and extensions.
- New tests copy the shape of `test/attributes/hx-get.js`: `makeServer()` and `clearWorkArea()` in `beforeEach`/`afterEach`, `make('<html>')`, `this.server.respondWith(...)`, a `.click()`, `this.server.respond()`, then a should-style assertion. Match its `var` and `function() {}` style.
- A new test file also needs a `<script>` tag in `test/index.html`. The headless runner finds files by glob, but browser mode loads only the listed ones.
- A behaviour change also updates its page under `www/content/`. Maintainers write `CHANGELOG.md` and rebuild `dist/` at release.

## Guardrails

- Edit `src/htmx.js`. `dist/` is regenerated by `npm run dist` at release, and the tests load `src/`, so an edit in `dist/` changes nothing.
- `www/static/src/`, `www/static/test/` and `www/themes/htmx-theme/static/js/htmx.js` are copies made by `scripts/www.sh`, and nothing runs them. `editors/jetbrains/htmx.web-types.json` is generated from the attribute docs. `test/lib/_hyperscript.js` is vendored.
- Run tests through the npm scripts above. `npx mocha` fails because the tests need a browser DOM and sinon's fake XHR.
- Remove `it.only` before finishing. Lint reports it only as a warning, so `npm test` passes while skipping the rest of that file.
- `npm run ws-tests` and `npm run update-sha` point at files that no longer exist.
